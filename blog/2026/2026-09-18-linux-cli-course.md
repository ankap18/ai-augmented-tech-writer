I just finished the course *Learning Linux Command Line*, something that had been sitting on my to-do list for a while. Ticking it off felt good, but it also left me with a question I couldn't shake.

<!-- truncate -->

## The why

While working through it, I kept asking myself: is this still relevant in the AI era?

If AI can generate a command in seconds, do we still need to understand what's happening under the hood? I've also heard developers talk about how AI-assisted coding changes the need to remember syntax and write everything from scratch.

After some vibe-coding (and quickly running out of tokens), it hit me that you still need to understand what you're doing. When AI hands you a command, you should know enough to decide whether it makes sense and what might happen if you run it.

## What I learned

I started from the basics, including setting up a Linux VM, and gradually got more comfortable on the command line. Some fun technical bits and trivia from the course:

- **The terminal is not the shell.** The terminal is the text interface; the shell is the program that interprets what you type. Bash stands for Bourne Again Shell.
- **`~` is your home.**
- **Ctrl+C isn't copy.** It interrupts a process (the `^C` is there to remind you).
- **Tab is your friend.** Autocomplete everything you can.
- **Spelling counts.** A lot :)
- **`man` is for manual.**
- **`777` might be a security risk.**
- **Linux was created by Linus Torvalds in 1991** and grew into a global open-source project. Open source = freedom.
- **Linus Torvalds is also the original author of Git.**

## Then I actually used it

The best part of learning something new is when it becomes useful. I recently needed to schedule my Mac to shut down automatically, but I couldn't find a ready-made tool for it. A bit of command-line knowledge did the job.

## The takeaway

It's a small example, but a good reminder that fundamentals still pay off. AI can write the command; knowing the basics is what lets you trust it, question it, or fix it when it's wrong :)
