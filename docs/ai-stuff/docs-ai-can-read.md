AI tools rarely read a docs page the way a person does. A search system splits the page into chunks, an agent fetches it and may cut it short, and a model may have learned it months ago from training data. These notes are about writing docs that hold up in all of those cases.

The notes come in three parts:

- **Overview** — what chunking is, how AI reads a page, and what makes a fact self-contained.
- **Practical guide** — what to do so your docs survive chunking, with examples.
- **Checking my docs** — how to check how AI would chunk a page, starting with the afdocs agent-docs audit I'm running on this site.
