Support knows the problems of users better than any other team. Support agents see the exact places where the docs fail.

Each team needs different things from the other team:

- **What support needs from writers** — articles to link in tickets, troubleshooting guides, and release notes that explain changes in behavior.
- **What writers need from support** — ticket trends, the search terms that customers use, and the questions that customers ask many times. Customers ask these questions even when a page about the topic exists.

## The feedback loop

Tickets show where the docs fail. You use this data to improve the docs. Support uses the improved docs to answer tickets. The bold steps show where you work directly with support:

1. Customers open tickets and search the help center.
2. **Agents report doc problems to you.** Agents use one Slack channel or one ticket tag for these reports. One channel is better than many different direct messages.
3. You review the ticket trends and search terms one time each month. Many tickets about one topic show a problem with a page. The page does not exist, is difficult to find, or is not clear.
4. You correct the page or write a new article.
5. **You tell the agent about the change.** The agent adds a link to the article in tickets. When agents see results, they trust the process and send more feedback.
6. You measure deflection. Deflection means that there are fewer tickets about that topic. You compare the number of tickets before and after the change. You also make sure that nothing else changed at the same time, such as a product fix. Then the result is clear proof of the value of the docs. You add new trends to the next review.

## Logs from AI chatbots

AI chatbots give the loop a new source of data. Their logs can show the exact information that a page does not contain. Users also ask the chatbot about features that do not exist. Product managers can use these questions as data for product decisions ([Biel.ai](https://biel.ai/blog/technical-writers-ai-chatbot-analytics-documentation-quality)).

Chatbot logs give you more data than before. But you still need agents to explain the context. A log shows what users asked. An agent can tell you why the users asked.
